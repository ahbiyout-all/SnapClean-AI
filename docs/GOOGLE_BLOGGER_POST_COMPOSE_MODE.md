# 2. 본문 (Main Description & Features)
스마트폰과 디지털카메라로 매일 늘어나는 수천 장의 사진, 어떤 사진이 진짜 보존할 가치가 있는 베스트 컷인지 일일이 대조하기 지치셨나요? 

**SnapClean AI**는 사용자의 저장 공간을 차지하는 중복 사진과 연사 컷을 온디바이스 AI로 초고속 탐지하고, **초점 선명도 · 노출 밸런스 · 피사체 구도**를 정밀 분석하여 최상의 원본 컷을 자동 보존해 주는 스마트 디지털 자산 관리 솔루션입니다.

정리 후 남겨진 소중한 추억들은 실제 책장을 넘기는 듯한 **인터랙티브 3D 감성 플립북 포토북**과 **전체화면 극장 모드(Theater Mode)**를 통해 아름다운 출판물급 스토리북으로 자동 재탄생합니다.

### 🌟 핵심 주요 기능
- **100% 온디바이스 프라이버시 보호**: 외부 클라우드 서버 전송 없이 내 기기 안에서만 안전하게 실행됩니다.
- **7대 다채널 중복 탐지**: 바이트 무결성, 시각적 지각 해시(pHash), 연사 시퀀스, 리사이즈 변환본, 파일명 패턴, 폴더 간 중복 완벽 선별.
- **D3.js 폴더별 용량 히트맵**: 저장 공간을 가장 많이 압박하는 '핫스팟 디렉터리'를 한눈에 시각화하고 원클릭 필터링.
- **AI 3D 디지털 포토북 2.0**: 감성 캡션 자동 작성, 종이 소리 효과, 앰비언트 글로우 및 슬라이드쇼 지원.

- 🚀 **GitHub Releases 실시간 라이브 자동 업데이트 알림**: 새 버전 배포 시 실행 화면에서 알림 팝업창이 자동 출력되어 원클릭 최신 패치 적용.
- ⚙️ **개별파일 설치형 (Unpacked Setup) & 조용한 방화벽 자동 등록**: 무인 설치(/S) 모드 및 기존 버전 자동 감지 덮어쓰기 지원.
