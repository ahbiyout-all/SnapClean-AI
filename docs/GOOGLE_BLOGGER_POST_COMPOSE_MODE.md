# 2. 본문 (Main Description & Features)
스마트폰, 카카오톡, 클라우드 백업으로 이리저리 이동하며 파일명이 바뀌어 버린 중복 사진들 때문에 고민이셨나요?

**SnapClean AI**는 파일 크기나 해시값이 일치하지 않거나, 메신저 전송으로 파일명이 달라진 사진까지 수학적 타임스탬프와 명명 패턴을 통해 지능적으로 찾아내는 **파일명 지능형 유추 중복 감지 엔진**을 탑재한 온디바이스 스마트 디지털 자산 관리 솔루션입니다.

단순 픽셀 수만 높은 흐린 사진 대신 **초점 선명도 · 노출 밸런스 · 피사체 구도**를 정밀 분석하여 최고 화질의 원본을 추천하고, 정리 후 남겨진 소중한 추억들을 감성 넘치는 **인터랙티브 3D 포토북**으로 감상할 수 있습니다.

### 🌟 핵심 주요 기능
- **파일명 지능형 유추 (Deductive Inference)**: 카카오톡·WhatsApp 전송본, 촬영일시(`YYYYMMDD_HHMMSS`) 시그니처, 사진 편집기 접미사(`_edit`, `_filter`), 카메라 특수 모드(`MVIMG`, `PXL`)를 자동 유추.
- **초점·노출·구도 3축 스마트 AI 선택**: 단순 해상도가 아닌 선명도와 노출 밸런스를 측정하여 최적의 사진을 자동 보존.
- **D3.js 폴더별 용량 히트맵**: 저장 공간을 낭비하는 핫스팟 디렉터리를 지각적 컬러로 한눈에 시각화하고 원클릭 필터링.
- **3D 인터랙티브 디지털 포토북**: 실제 종이 책장을 넘기는 손맛과 사운드, 감성 AI 캡션과 극장 모드 슬라이드쇼.
- **100% 온디바이스 프라이버시**: 개인 사진이 외부 서버로 전송되지 않고 내 PC 로컬에서 안전하게 처리됩니다.
