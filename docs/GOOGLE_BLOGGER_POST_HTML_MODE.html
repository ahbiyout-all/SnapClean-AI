Official Release

📸 [SnapClean AI v2.5.0] 스마트 AI 중복 사진 정리 & D3.js 히트맵과 감성 3D 디지털 포토북

💡 지저분한 갤러리 정리부터 감성 포토북 완성까지!

스마트폰과 카메라로 매일 쌓여가는 수천 장의 사진, 어떤 사진이 진짜 보존할 가치가 있는지 일일이 대조하기 지치셨나요?

SnapClean AI는 저장 공간을 차지하는 중복 사진과 연사 컷을 온디바이스 AI로 초고속 탐지하고, 초점 선명도 · 노출 밸런스 · 피사체 구도를 정밀 분석하여 최상의 원본 컷을 자동 보존해 주는 스마트 디지털 자산 관리 솔루션입니다.

정리 후 남겨진 소중한 추억들은 실제 책장을 넘기는 듯한 인터랙티브 3D 감성 플립북 포토북과 전체화면 극장 모드(Theater Mode)를 통해 아름다운 출판물급 스토리북으로 자동 재탄생합니다.

  • 🔒 100% 온디바이스 프라이버시 보호: 외부 서버 전송 없이 내 기기 안에서만 안전하게 실행
  • 🔍 7대 다채널 중복 탐지: 바이트 무결성, 시각적 유사도(pHash), 연사, 리사이즈, 파일명 패턴 매칭
  • 📖 AI 3D 디지털 포토북 2.0: 감성 캡션 자동 작성, 종이 소리 효과, 앰비언트 글로우 및 슬라이드쇼

🚀 v2.5.0 핵심 신규 업데이트 내역

  • 🔥 D3.js 중복 폴더 히트맵 (Storage Hotspots): 낭비 용량이 가장 큰 핫스팟 폴더를 D3.js 그리드로 한눈에 시각화하고 원클릭 필터링 지원.
  • ✨ 초점·노출·구도 3축 스마트 AI 자동 선택: Laplacian Variance 선명도와 적정 노출, 구도 점수를 종합 평가하여 최상 화질 원본 자동 지정.
  • 🚀 GitHub Releases 실시간 라이브 자동 업데이트 알림: 실행 시 새 버전 자동 감지 및 원클릭 업데이트 팝업 제공.
  • ⚙️ Unpacked Setup 패키징 & 조용한 방화벽 자동 등록: 무인 설치(/S) 지원 및 Windows 방화벽 인바운드 규칙 자동 등록.
