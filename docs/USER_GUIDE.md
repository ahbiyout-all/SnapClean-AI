# SnapClean AI - 사용자 가이드 (User Guide)

SnapClean AI의 주요 기능과 사용 방법을 안내합니다.

---

## 1. 시작하기 (Getting Started)

### 1.1. 파일 스캔 및 폴더 선택
1. 상단 또는 좌측의 **「스캔 시작 (Start Scan)」** 버튼을 클릭합니다.
2. 정리하고자 하는 대상 폴더(예: `C:\Users\<사용자>\Pictures`, 외장 드라이브, SD 카드 등)를 선택합니다.
3. 스캔 필터 설정에서 분석할 미디어 확장자(일반 사진: JPG, PNG, HEIC, WEBP / RAW 고화질: DNG, CR2, NEF, ARW / 동영상: MP4, MOV 등)를 선택할 수 있습니다.
   - *안내: 일반 문서(`.pdf`, `.docx`, `.txt`) 및 시스템 파일은 사진 정리 앱의 목적과 데이터 안전을 위해 스캔 대상에서 자동으로 제외됩니다.*
   - *안전 보호: `C:\Windows`, `Program Files`, `AppData`, `node_modules` 등 주요 OS 및 시스템 폴더는 자동으로 보호 및 바이패스됩니다.*
4. 스캔 시작 즉시 **점진적 스트리밍 검색(Progressive Streaming Discovery)**이 작동하여 1~2초 내에 발견된 중복 사진을 상단 배너로 즉시 확인할 수 있습니다.

### 1.2. 점진적 스트리밍 검색 & 즉시 정리 (Progressive Discovery)
- 전체 심층 AI 분석이 백그라운드에서 진행되는 동안에도 상단에 **`[발견된 사진 즉시 정리]`** 배너가 나타납니다.
- 사용자는 전체 스캔이 끝날 때까지 기다릴 필요 없이 즉시 중복 탭으로 이동하여 발견된 항목을 즉각 정리할 수 있습니다.

### 1.3. 백그라운드 스마트 증분 동기화 (Background Sync Hub)
- **동기화 탭(Sync Hub)**에서 자동 감시 주기(`실시간 감시(10분)`, `1시간`, `6시간`, `충전/유휴 시`, `수동`)를 설정할 수 있습니다.
- **증분 차분 검사**: 매번 전체를 재스캔하지 않고 파일 수정일시(`mtime`)와 크기를 비교하여 변경된 파일만 0.1초 만에 초고속으로 동기화합니다.
- **배터리 보호 모드**: 노트북이나 모바일 기기 배터리가 20% 미만일 때 백그라운드 작업을 일시 정지하여 전력을 보존합니다.

## 2. 중복 파일 정리 (Duplicates Management)

### 2.1. 3가지 보기 모드 전환
화면 상단의 모드 전환 버튼을 통해 원하는 스타일로 중복 파일을 검토할 수 있습니다:

| 보기 모드 | 설명 | 추천 상황 |
|---|---|---|
| **📊 자세히 보기 (Details)** | Windows 파일 탐색기 스타일의 고정밀 데이터 테이블. 파일명, 폴더 경로, 크기, 수정일자, EXIF 촬영일자, 해상도, 카메라 기종을 컬럼별로 정렬 및 비교 | 정확한 경로 및 메타데이터 정밀 비교 시 |
| **📋 리스트 뷰 (List)** | 카드형 비교 목록. 원본 대비 용량 차이(`+5.2 MB` 등)와 날짜/해상도 차이를 시각적 배지로 강조 | 직관적인 파일 크기 및 스펙 비교 시 |
| **🖼️ 그리드 뷰 (Grid)** | 썸네일 중심의 비주얼 그리드 레이아웃 | 사진 품질 및 비주얼을 빠르게 훑어볼 때 |

### 2.2. 파일 열기 및 Windows 연결 프로그램 실행
- **더블클릭**: 테이블 행 또는 썸네일을 **더블클릭**하면 Windows 기본 사진 뷰어/플레이어로 즉시 실행됩니다.
- **열기 버튼**: 각 항목의 `열기` 또는 `외부 링크` 아이콘을 클릭하여 실행할 수 있습니다.
- **마우스 우클릭**: 컨텍스트 메뉴를 열어 `Windows 연결 프로그램으로 열기`, `전체 경로 복사`, `폴더 위치 복사`를 수행할 수 있습니다.

### 2.3. 스마트 보존(KEEP) 및 삭제(PURGE) 지정
1. **AI 자동 추천 (Best Shot)**: 해상도가 가장 높고 선명도가 우수한 원본 사진에 `★ BEST` 배지가 자동으로 부여되고 보존 대상으로 기본 설정됩니다.
2. **이 파일만 유지 (Keep Only)**: 여러 중복 파일 중 원하는 항목의 `이 파일만 유지`를 클릭하면 해당 파일만 보존되고 나머지는 삭제 대상으로 변경됩니다.
3. **개별 토글**: 체크박스나 `보존 / 삭제` 버튼을 클릭하여 개별 파일의 유지 여부를 수동으로 변경할 수 있습니다.
4. **일괄 최적화 (Optimize)**: 그룹 우측 상단의 `보존 N • 삭제 M` 버튼을 클릭하면 그룹 내 정리 대상 파일이 안전하게 처리됩니다.

## 3. 라이브러리 및 탐색기 (Library Tab)

- **정렬 기능**: 파일명, 촬영일자, 크기, 카테고리 헤더를 클릭하여 오름차순/내림차순으로 즉시 정렬할 수 있습니다.
- **경로 복사**: 폴더 위치의 복사 아이콘을 클릭하여 클립보드로 전체 경로를 간편하게 복사할 수 있습니다.
- **다중 선택**: 다중 선택 모드를 활성화하여 여러 자산을 한 번에 선택하고 일괄 작업할 수 있습니다.

---

## 4. 단축키 (Keyboard Shortcuts)

- `Ctrl + K` (또는 `Cmd + K`): 빠른 명령어 팔레트 (Command Palette) 실행
- `Ctrl + S`: 즉시 라이브러리 스캔 시작
- `Ctrl + F`: 라이브러리 검색창으로 바로 이동
- `Esc`: 열려 있는 모달 닫기
